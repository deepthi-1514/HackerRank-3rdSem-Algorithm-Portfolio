## Introduction

This repository contains my solutions to five algorithmic problems completed as part of my 3rd Semester coding portfolio. The solutions are implemented in C++ and focus on basic algorithmic techniques, sorting, searching, and efficient problem solving.

## Problems and Approaches

### 1. Mini-Max Sum

**Approach:**  
Calculate the total sum of the five numbers while finding the minimum and maximum values. The minimum sum is obtained by subtracting the maximum value from the total, and the maximum sum is obtained by subtracting the minimum value.

**Time Complexity:** O(N)  
**Space Complexity:** O(1)

### 2. Birthday Cake Candles

**Approach:**  
Traverse the array once while keeping track of the maximum candle height and the number of candles having that height.

**Time Complexity:** O(N)  
**Space Complexity:** O(1)

### 3. Insertion Sort – Part 1

**Approach:**  
Store the last element as the value to be inserted. Shift larger elements one position to the right until the correct position for the value is found.

**Time Complexity:** O(N)  
**Space Complexity:** O(1)

### 4. Binary Search

**Approach:**  
Use two pointers, `low` and `high`, to repeatedly divide the sorted array into halves. Compare the middle element with the target and continue searching in the appropriate half.

**Time Complexity:** O(log N)  
**Space Complexity:** O(1)

### 5. Mark and Toys

**Approach:**  
Sort the prices in ascending order and purchase the cheapest toys first while the total cost remains within the given budget.

**Time Complexity:** O(N log N)  
**Space Complexity:** O(1) auxiliary space
